Servidor MCP

    
Un servidor MCP real por stdio (Node, sin red, sin secretos) que sirve los mismos cuatro tools desde public/agent/*.json. Corre localmente en tu máquina — esta página solo documenta el contrato.

    
tools: get_profile, list_projects, get_project, search_publications · leen public/agent/*.json

    
Config del cliente (p. ej. cualquier host MCP):

    
{
  "mcpServers": {
    "profile": {
      "command": "node",
      "args": [
        "mcp/server.mjs"
      ]
    }
  }
}
